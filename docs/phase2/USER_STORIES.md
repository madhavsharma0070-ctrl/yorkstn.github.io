# Yorkstn — User Stories

Organized by module. Format: `As a <persona>, I want to <action>, so that <value>.` Each story references the persona from `PERSONAS.md` and is the basis for acceptance criteria in `ACCEPTANCE_CRITERIA.md`.

## Onboarding

- **US-01.** As Daniel (Founder), I want to create an organization and a brand profile in under 5 minutes, so that I can start seeing India market intelligence for my category without a sales call.
- **US-02.** As Priya (VP International), I want to invite my Compliance Manager and Analyst to the organization with the right roles, so that we can collaborate without over-sharing access.
- **US-03.** As any new user, I want to see a guided first-session path (Readiness Score → City Recommendations → next steps), so that I know where to start.

## AI Market Intelligence

- **US-10.** As Priya, I want an India market analysis for my brand's category (e.g., "premium kids apparel"), so that I can assess market size and trend direction with sources I can defend internally.
- **US-11.** As Priya, I want consumer insight summaries broken down by region/city tier, so that I understand where my target consumer actually is in India, not just a national average.
- **US-12.** As Meera (Analyst), I want a list of competitors already operating in my category in India with their channel/price-point positioning, so that I can identify white space.
- **US-13.** As Priya, I want a recommended India price point for my products relative to my home-market pricing, so that I can sanity-check margin viability before committing.
- **US-14.** As Priya, I want a demand forecast for my category that does **not** require my own India sales history, so that I can get a usable estimate as a true first-time entrant (the Phase 1-identified "cold start" gap).
- **US-15.** As Priya, I want a ranked shortlist of Indian cities matched to my brand's category, price point, and target consumer, so that I don't have to evaluate all of India from scratch.
- **US-16.** As Priya, I want a composite "Expansion Readiness Score" summarizing my documented compliance, capital, and category-fit status, so that I have one number and its drivers to bring to my board.
- **US-17.** As any user viewing an AI-generated output, I want to see its sources and generation date, so that I can judge how current/reliable it is (per the platform's citation standard).

## Compliance Operating System

- **US-20.** As Arjun (Compliance Manager), I want a guided decision tool for entity type (WOS/JV/LLP/Branch/Liaison) based on my brand's operating model, so that I choose the right structure before filing anything.
- **US-21.** As Arjun, I want an import compliance checklist scoped to my product's HSN code, so that I know exactly which IEC/DGFT/CBIC/BIS steps apply to me and which don't.
- **US-22.** As Arjun, I want to track GST registration status per state as my footprint (warehouses/stores) grows, so that I never miss a state-triggered registration requirement.
- **US-23.** As Arjun, I want to track BIS/QCO certification status per product line, so that I know what's certified, what's pending, and what's blocking launch.
- **US-24.** As Arjun, I want to track trademark/IP filing status and key dates (opposition window, examination), so that I don't miss a deadline that jeopardizes brand protection.
- **US-25.** As Arjun, I want to upload and version documents against each compliance workflow, so that filings, certificates, and POAs are in one auditable place.
- **US-26.** As Arjun, I want a single cross-workflow timeline of every open compliance task and its due date, so that I can see what's overdue or at risk at a glance.
- **US-27.** As Arjun, I want every compliance rule/checklist item to show a "last verified" date and source, so that I know if something might be stale given how fast Indian regulation changes.
- **US-28.** As Ananya (Yorkstn Staff), I want to be assigned to specific organizations' compliance cases for managed-services delivery, so that I can act on their behalf without seeing unrelated organizations' data.

## Partner Discovery

- **US-30.** As Meera, I want to search and filter partners by category (manufacturer, franchise, retail, mall operator, CRE, logistics, warehousing, marketing agency, legal), city, and verification status, so that I can build a relevant shortlist quickly.
- **US-31.** As Meera, I want to view a verified partner's profile (verification status, documents on file, references), so that I can trust who I'm engaging with — unlike unverified directory listings elsewhere.
- **US-32.** As Meera, I want AI-generated partner recommendations matched to my organization's profile and expansion plan, so that I don't have to manually search every category from scratch.
- **US-33.** As Meera, I want to send an introduction request to a partner and track its status, so that I have a record of outreach inside the platform.
- **US-34.** As Rohan (Partner), I want to build and submit a verification profile, so that I become discoverable to relevant international brands.
- **US-35.** As Ananya (Yorkstn Staff), I want to review and approve/reject partner verification submissions, so that only credible partners appear as "verified" to brands.

## Retail Expansion Intelligence

- **US-40.** As Meera, I want a city intelligence detail view (demographics, competitive density, real-estate cost, distribution maturity), so that I can go deeper than the ranked shortlist before committing.
- **US-41.** As Meera, I want mall intelligence (tenant mix, lease benchmark ranges, footfall proxies), so that I can evaluate specific mall opportunities within a chosen city.
- **US-42.** As Meera, I want a site-selection workspace that scores candidate sites against my brand's criteria, so that I can compare options systematically rather than ad hoc.
- **US-43.** As Priya, I want an expansion roadmap sequencing entity formation → compliance → partners → site selection → launch, so that my team knows what depends on what.
- **US-44.** As Priya, I want a financial projections workspace I can populate with my own assumptions (rent, staffing, COGS) against platform-provided market benchmarks, so that I get a defensible model without the platform overstating certainty.
- **US-45.** As Meera, I want a launch-planning task/timeline view, so that go-live execution is tracked in the same place as the strategic plan.
- **US-46.** As Priya, I want an Expansion Dashboard summarizing status across all four modules, so that I have one home screen when I return to the platform.

## Managed Services

- **US-50.** As Priya or Daniel, I want to request a managed-services engagement (e.g., "execute my entity formation") directly from the relevant Compliance OS workflow, so that I can get expert help exactly where I need it without leaving the platform.
- **US-51.** As Ananya, I want to see and update the status of managed-services engagements assigned to me, so that the brand always sees current status inside their own dashboard.

## Platform / Cross-cutting

- **US-60.** As an Owner/Admin, I want to manage member roles and permissions, so that access matches responsibility.
- **US-61.** As any user, I want an audit log of who changed what across compliance and partner data, so that the organization has accountability, especially for managed-services actions taken on their behalf.
- **US-62.** As an Owner/Admin, I want to manage billing/subscription tier, so that I control module access and cost.
